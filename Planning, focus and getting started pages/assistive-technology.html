Tools to try on your own

Apps, timers and websites that can help with focus, routines, research, writing and reading on screen.

Not run by CMU. Each link opens the tool’s own website.

CMU’s assistive technology list

Opens the Office of Disability Resources list in a new tab.

Tools

These are suggestions, not endorsements. What works for someone else may not work for you. Prices and features can change, so check each site.

Show

Otter.ai

Note taking and transcription

Records lectures and meetings and turns them into searchable notes and summaries.

  • Free plan, student discount
  • Web, Mac, Windows, iPhone, Android
Visit site: Otter.ai (opens in a new tab)

Voice-activated teleprompter

Presenting

Scrolls your script as you speak, so you can present without losing your place.

Visit site: Voice-activated teleprompter (opens in a new tab)

Colorveil

Reading on screen

Puts a color tint over your screen to ease eye strain or visual stress when reading.

  • Free
  • Windows PC
Visit site: Colorveil (opens in a new tab)

Pomofocus

Pomodoro timer

A simple Pomodoro timer that splits work into focus blocks and short breaks.

  • Free, optional premium
  • Web, Mac, Windows, Linux
Visit site: Pomofocus (opens in a new tab)

Cuckoo

Shared timer

A work and break timer you can share, so a group works on the same clock.

  • Web
Visit site: Cuckoo (opens in a new tab)

Time Timer

Visual timer

A red disk shrinks as time runs out, so you can see time passing.

  • Paid
  • Physical timer, iPhone app
Visit site: Time Timer (opens in a new tab)

Hexagon rotating timer

Visual timer

A small timer you flip to a side to start a countdown.

  • Physical timer
Visit site: Hexagon rotating timer (opens in a new tab)

Alarmy

Alarm clock

An alarm you can’t snooze forever: do a task, like a math problem or a photo, to turn it off.

  • Free, optional paid features
  • iPhone, iPad, Android
Visit site: Alarmy (opens in a new tab)

Forest

Focus timer

Grow a virtual tree while you focus. Leave the app and the tree dies.

  • Free, optional subscription
  • iPhone, Android, Chrome, Firefox
Visit site: Forest (opens in a new tab)

SelfControl

Website blocker

Blocks distracting websites, your email or anything else online for a set time, with no early undo.

  • Free
  • Mac only
Visit site: SelfControl (opens in a new tab)

Connected Papers

Finding sources

Shows a map of papers related to one you choose, to help you find sources.

  • Web
Visit site: Connected Papers (opens in a new tab)

Litmaps

Literature reviews

Maps how research papers cite each other, to help with literature reviews.

  • Free plan, paid Pro
  • Web
Visit site: Litmaps (opens in a new tab)

Scrivener

Long writing projects

Writing software that keeps drafts, notes and research for long projects in one place.

  • Paid, free trial
  • Mac, Windows, iPhone, iPad
Visit site: Scrivener (opens in a new tab)

Brili

Daily routines

A visual daily routine app built for people with ADHD.

  • Paid, free trial
  • iPhone, Android
Visit site: Brili (opens in a new tab)

Habitica

Habits and to-dos

Turns habits and to-dos into a game to help with everyday life tasks.

  • Free
Visit site: Habitica (opens in a new tab)

Bullet journal

Paper planning

One person’s simple paper bullet journal setup for managing ADHD.

  • Free to read
  • Article
Visit site: Bullet journal (opens in a new tab)
